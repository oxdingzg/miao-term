# mtty v0.1.3

- **改用内置字体作为默认。** mtty 打包了 JetBrains Mono,但字体系统实际回退到了
  Courier New,而它没有制表符 U+2503(`┃`,miao 给消息画的左边框)和工具前导符
  U+23BF(`⎿`)。在 Windows 上缺失的 `┃` 显示成了每行左侧的 `z`。现在 JetBrains Mono
  是默认等宽字体,`⎿` 用 `└` 替代。

验证在 GitHub Actions 上运行:完整的 workspace CI 与性能门禁,随后是四个 runner 的打包与安装器检查。

[完整变更](https://github.com/oxdingzg/mtty/compare/v0.1.2...v0.1.3)
