# mtty v0.1.3

- **The bundled font is now the default.** mtty ships JetBrains Mono but the
  font system fell back to Courier New, which lacks box-drawing U+2503 (`┃`,
  the left border miao draws on messages) and the tool marker U+23BF (`⎿`).
  On Windows the missing `┃` showed as a stray `z` on every message line.
  JetBrains Mono is now the monospace default, and `⎿` stands in as `└`.

Verification runs on GitHub Actions: full workspace CI and performance gates,
followed by four-runner packaging and installer checks.

[Full changes](https://github.com/oxdingzg/miao-term/compare/v0.1.2...v0.1.3)
