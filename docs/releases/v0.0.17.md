# mtty v0.0.17

[简体中文](v0.0.17.zh-CN.md)

The editor becomes a peer of the terminal, and the remote (PuTTY-style) and
AI-native feature sets are filled in.

## Editor

- **Remote files open in the editor pane.** *View/Edit Remote File…* reads and
  writes over ssh; the pane keeps no local stamp, gets no language server, and
  titles itself `host:name`. Remote panes come back after a restart by
  re-reading their host (ADR 0034, E3).
- **A lone editor pane can be closed.** It now has its own ×, so a code file no
  longer needs the whole tab closed; an unsaved one arms on the first click and
  discards on the second.

## Agents

- **Agent edits are reviewable.** MTP `editor.propose` applies an agent's
  changes as one undoable transaction, tints the changed lines and shows them
  in the status bar. *Accept Agent Edit* keeps the text; *Reject Agent Edit* is
  one undo step back (ADR 0040, A1).
- **Hand context to an agent in one step.** *Send Selection to Agent*, *Send
  Diagnostics to Agent* and *Send Last Command Output to Agent* type a short,
  fenced prompt into the tab's agent pane. MTP `app.edit`/`app.view` can open a
  file at a line and column (A3).
- **Any ACP agent works.** *ACP Agent…* starts an agent that speaks the Agent
  Client Protocol (from `config.toml`'s `[acp]`, or a typed command), streams
  its transcript, sends prompts, turns its diffs into reviewable proposals and
  answers permission requests with Allow/Deny (ADR 0040, A2).

## Remote

- **Serial, Telnet and raw TCP sessions.** *New Serial/Telnet/TCP Session…*
  opens a serial console (baud, data bits, parity, stop bits, flow), a Telnet
  connection or a raw TCP socket as a pane. Saved hosts carry a `kind`; Telnet
  and raw TCP are marked unencrypted. Sessions reconnect on restore and close
  when the connection drops (ADR 0037, R1).
- **Import PuTTY keys.** *Hosts… → Import PuTTY Key…* reads a `.ppk` (v2 or v3,
  Ed25519/RSA/ECDSA) and writes a passphrase-encrypted OpenSSH key to `~/.ssh`;
  it is never stored unencrypted (ADR 0038, R2).

## Verification

- Full CI on macOS, Linux and Windows, and the four-runner packaging, on the
  release commit.
- New unit tests: editor proposals (one-transaction apply, undo, accept),
  remote-pane load/save, the Telnet codec and pipe terminal, host kinds, PPK
  import against real `puttygen` 0.81 fixtures (Ed25519/RSA/ECDSA × v2/v3 ×
  plain/encrypted), the `[acp]` config, and the ACP client against a fake agent.
- `cargo fmt`, workspace `clippy --all-targets` and workspace `cargo test` on
  the macOS and Linux build hosts; `scripts/check-privacy.sh`.
