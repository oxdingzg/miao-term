# mtty v0.0.17

编辑器成为与终端对等的 pane,远程(PuTTY 式)与 AI 原生功能也补齐。

## 编辑器

- **远端文件在编辑器 pane 中打开。***查看/编辑远端文件…* 经 ssh 读写;pane 不保存
  本地磁盘戳、不启用语言服务器,标题为 `host:name`。远端 pane 重启后通过重新读取主机
  恢复(ADR 0034,E3)。
- **单独的编辑器 pane 可以关闭。** 它现在有自己的 ×,代码文件不必再关掉整个标签;
  有未保存修改时第一次点击先确认,第二次丢弃。

## Agent

- **agent 的修改可审阅。** MTP `editor.propose` 把 agent 的修改作为**一个可撤销事务**
  应用,给改动行上色并在状态栏显示。*接受 Agent 修改* 保留文本;*拒绝 Agent 修改* 是
  一步撤销回到原样(ADR 0040,A1)。
- **一步把上下文交给 agent。***把选区发给 Agent*、*把诊断发给 Agent*、*把上一条命令的输出
  发给 Agent* 会把一段带围栏的简短 prompt 输入到本标签的 agent pane。MTP
  `app.edit`/`app.view` 可在指定行、列打开文件(A3)。
- **任意 ACP agent 可用。***ACP Agent…* 启动一个支持 Agent Client Protocol 的 agent
  (来自 `config.toml` 的 `[acp]`,或直接输入命令),流式显示转写、发送 prompt、把其 diff
  变成可审阅的提案,并以“允许/拒绝”应答权限请求(ADR 0040,A2)。

## 远程

- **串口、Telnet 与裸 TCP 会话。***新建串口/Telnet/TCP 会话…* 把串口控制台(波特率、
  数据位、校验、停止位、流控)、Telnet 连接或裸 TCP socket 作为 pane 打开。已保存主机带
  `kind`;Telnet 与裸 TCP 标注为未加密。会话恢复时重连,连接断开即结束(ADR 0037,R1)。
- **导入 PuTTY 密钥。***主机… → 导入 PuTTY 密钥…* 读取 `.ppk`(v2 或 v3,
  Ed25519/RSA/ECDSA),写出经口令加密的 OpenSSH 密钥到 `~/.ssh`;绝不明文保存
  (ADR 0038,R2)。

## 验证

- 发布提交上完整的 macOS/Linux/Windows CI,以及四 runner 打包。
- 新增单元测试:编辑器提案(单事务应用、撤销、接受)、远端 pane 的读写、Telnet 编解码与
  管道终端、主机类型、用 `puttygen` 0.81 生成的真实 PPK 夹具导入(Ed25519/RSA/ECDSA ×
  v2/v3 × 明文/加密)、`[acp]` 配置解析,以及 ACP 客户端对假 agent 的测试。
- 在 macOS 与 Linux 构建机上跑 `cargo fmt`、workspace `clippy --all-targets` 与
  workspace `cargo test`;`scripts/check-privacy.sh`。
