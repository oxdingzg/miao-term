# mtty v0.0.8

[简体中文](v0.0.8.zh-CN.md)

A window-layout release, with two fixes in the editor and
Markdown preview.

## Changes

- **Full-height session sidebar.** The session list now runs from the top of
  the window to the bottom, with `+` (new tab) and the sidebar toggle in its
  header. Rows can be dragged to reorder tabs, and a divider marks where a tab
  group changes.
- **A title row instead of the tab strip.** Beside the sidebar header, the
  active tab's title is centred and the panel and font controls (details,
  sidebar, A-, A+) sit at the top right. With the sidebar hidden, the row shows
  the inline tab bar again (`+`, `×`, drag to reorder).
- **macOS: transparent title bar.** In the installed app the content extends
  under the title bar, so the traffic lights sit in the sidebar header. Empty
  space in the title row moves the window, and a double-click zooms it. A bare
  `mtty` binary, which draws its own menu, keeps the standard title bar.

## Fixes

- **Floating windows resized only one way from the corner.** Dragging the
  bottom-right corner of the editor (or Settings, Hosts and the other floating
  windows) changed only the width or only the height. egui 0.30 resolves a tie
  between overlapping grab areas in favour of the thinner one, so an edge
  always beat the corner; corners are now grabbed first.
- **Markdown tables cut off long cells.** In the Markdown preview a long table
  cell stopped at the window edge, and scrolling could not reveal the rest.
  Cells now wrap inside the preview (patched `egui_commonmark`, see
  `vendor/egui_commonmark/PATCHES.miao.md`).
- **macOS: a blank strip above the terminal.** The app reserved the height of
  an in-window menu it does not draw; the terminal now starts right below the
  title row.

## Verification

- Full CI on macOS, Linux and Windows, and the four-runner packaging, on the
  release commit.
- Replay tests for the new layout (terminal area matches the host's grid,
  title-row drag regions, session-row drag reorder, group dividers), the corner
  resize and table wrapping; the latter two fail without their fixes.
- The macOS app built from these commits was captured on a Mac mini, and the
  new layout (sidebar with the traffic lights, top-right controls) was checked
  on a MacBook desktop. Corner resize and table wrapping are covered by the
  tests above.

## Known limits

- **Markdown tables with long cells can draw columns over each other.**
  **Fixed in [v0.0.9](v0.0.9.md).**
- Builds are not notarized (macOS) or code-signed (Windows) yet.
- The new layout has been checked on a real desktop on macOS only; on Linux and
  Windows it is covered by the replay tests.
- mosh support is tested only as command construction; the AppImage and
  Windows install-and-relaunch helpers are unit-tested but have not run on
  those desktops.
