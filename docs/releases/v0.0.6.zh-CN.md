# mtty v0.0.6

第一个以 **mtty**(原 miaotty)为名的版本,也是第一个按产品路线图推进的版本:已有功能的可靠性修复、代理工作流、
带 SSH/SFTP/FTP 运维能力的主机库,以及经过校验的更新。官网:<https://mtty.dev/zh/mtty>。

## 从 miaotty 升级

- 应用、命令与 bundle 现在分别是 `mtty` / `mtty-cli` / `mtty.app`(bundle ID `dev.mtty.terminal`)。macOS 上安装
  `mtty.app` 后可删除旧的 `miaotty.app`。
- mtty 首次启动会把 `~/.config/miaotty` 复制到 `~/.config/mtty`(只复制一次)。它仍读取 `MIAOTTY_*` 变量、响应
  `miaotty://` 链接与旧的控制 socket,并导出旧的 pane 变量,已安装的钩子和 miao 不受影响。详见
  [ADR 0032](../decisions/0032-rename-mtty.zh-CN.md)。
- v0.0.5 只会检查更新,请下载本版本手动升级。从 v0.0.6 起,mtty 可以自行下载、校验并安装更新(见下文)。

## 主要变化

**代理**
- 从 mtty 启动 Claude Code、Codex 等代理;为每种代理复制可直接合并的钩子配置。
- 提示队列:排队的提示会在对应 pane 的代理转为空闲时发出。需要关注的后台标签会被标记,通知会切到对应标签。
- 通过 OSC 133 捕获每条命令的输出:*复制上一条命令的输出*、*把上一条命令的输出发到 Composer*。
- 基于 git worktree 的代理任务:创建、查看差异、合并或丢弃。

**主机与远程工作**
- 主机库(`~/.config/mtty/hosts.toml`,可从 `~/.ssh/config` 导入),支持分组、标签与跳板机;主机密钥检查、ssh-agent
  状态与密钥配置 —— 不保存任何密码或密钥。
- 按主机的端口转发、SFTP 文件浏览器、经系统 `curl` 的 FTP/FTPS(口令只留在内存),以及可选的 tmux/mosh 持久会话。
- 可在本机或多台主机上执行的命令片段,以及向标签内所有 pane 广播输入。

**平台**
- 经校验的更新:在程序内校验 SHA-256 与必需的 minisign 签名,再 *安装并重启*(macOS 支持回滚、AppImage、
  Windows MSI/zip)。
- 在 zsh 之外新增 bash、fish 与 PowerShell 的 shell 集成(cwd、命令边界、历史),不修改你的点文件。
- 可选的端到端加密同步:主机与片段经你已在同步的文件夹(iCloud Drive、Dropbox、Syncthing)传递。默认关闭,
  无需账号、没有服务器([ADR 0033](../decisions/0033-encrypted-sync.zh-CN.md))。
- Linux 与 Windows 的快捷键改为以 Ctrl+Shift 为主(Alt+1…9 切换标签),Super/Win 留给桌面;见 README 表格。

## 修复

- **Windows:mtty 启动即退出**,报 `No font data found for "cjk"` —— CJK 字体列表只有 macOS 与 Debian 路径。现在会
  使用 Windows 系统字体(以及更多 Linux 路径),找不到也不会再崩溃。
- 在终端里按 **Tab** 不再把界面焦点移到 File 菜单并吞掉后续输入。
- 原生 Wayland:拖放文件现在会粘贴其路径,粘贴也保持可用(GNOME 每个客户端只认一个 data device)。
- 侧栏与应用内窗口可调整大小;网络与进程操作不再阻塞界面;回车可提交对话框、查找与面板;重命名的标签保持名称;
  输入法候选框跟随终端光标。
- macOS:从浏览器或 Finder 打开的链接能交给 mtty;恢复的 SSH 标签会提示重连。

## 验证

- 发布提交上完整的 macOS、Linux、Windows CI,以及四个 runner 的打包演练。
- 在真实的 Ubuntu 24.04 / GNOME 46 / Wayland 桌面上(经 uinput 注入输入)检查:键盘输入、菜单、拼音输入法、文件
  拖放、剪贴板、新快捷键、Tab 补全,以及通过 GNOME 自定义快捷键实现的 Quick Terminal 热键(GNOME 46 没有
  GlobalShortcuts portal)。
- macOS 上,*更新并重启* 端到端安装了测试签名的包,篡改过的包被拒绝。
- Windows 11:启动修复已在真实桌面上验证;其余 Windows 桌面检查(输入法、拖放、热键)仍在进行。

## 已知限制

- 构建尚未经过 macOS 公证或 Windows 代码签名。
- **Windows:使用输入法后 mtty 可能停止响应。** 在一台 Windows 11 测试机上,切换到中文输入法、输入并上屏、再切回后,
  窗口卡死 —— 搜狗拼音和微软拼音都出现过。如遇到,请在任务管理器中结束 mtty。不使用输入法的输入不受影响。**已在 [v0.0.7](v0.0.7.zh-CN.md) 修复**,该版本同时修复了 Windows 上的 SSH 会话与设置。
- mosh 只验证了命令构造,未对真实 mosh-server 测试。AppImage 与 Windows 的安装辅助脚本有单元测试,但尚未在这两类
  桌面上实际运行。
