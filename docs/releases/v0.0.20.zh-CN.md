# mtty v0.0.20

Windows 统一使用与 macOS 相同的 mtty 图标素材，并补齐安装后的启动入口。

- **程序和运行窗口图标。** Windows exe 嵌入 16 至 256 像素的七种图标尺寸，
  窗口和任务栏加载该资源，不再使用 Windows 默认图标。
- **安装后的应用图标。** MSI 为 Windows 设置中的已安装应用配置同一图标。
- **可见的启动入口。** MSI 在开始菜单和桌面创建 mtty 快捷方式，均使用应用图标，
  卸载时一并移除。
- **打包验证。** Windows CI 在打包前和 MSI 安装后，逐一比对 exe 内嵌图标
  与共享素材，并检查安装后的应用图标注册及快捷方式目标。

验证在 GitHub Actions 上执行：完整 workspace CI 与性能门禁，以及四 runner 打包和
安装包检查。本机无需编译。
