# mtty v0.0.15

在 v0.0.14 基础上修复一个显示问题。

## 修复

- **拖入或粘贴的路径几乎看不见。** zsh 会用反显高亮粘贴的文字。mtty 按反显的要求，用背景色绘制文字，单元格背景却仍按它本来的颜色绘制；
  默认颜色的单元格根本不绘制背景。结果路径成了深色背景上的深色文字。现在反显单元格改用文字颜色作背景，路径显示为浅底深字。

## 验证

- 发布提交在 macOS、Linux、Windows 上跑完整 CI，并完成四个 runner 的打包。
- 新增测试：检查默认颜色和彩色反显单元格的背景色与文字颜色。
- 用打包好的 macOS 应用截图验证：粘贴的路径后面有一条浅色底。
