# mtty v0.0.10

[简体中文](v0.0.10.zh-CN.md)

The first release of the editor pane (ADR 0034). It adds syntax highlighting
for 80 languages plus a fallback for many more, and brings back terminal
contents when mtty reopens.

## New

- **Editor pane.** Local files other than Markdown now open in an editor pane
  inside the tab, beside the terminals, instead of in the floating window. It
  can be split like a terminal.
  - **Drawing.** Text goes through the terminal renderer: line numbers, the
    current line, selections and carets, with long lines clipped at the pane.
  - **Keys.** macOS text conventions (Ctrl on Linux and Windows). While an
    editor has focus, its shortcuts win over the app's: ⌘D selects the next
    occurrence and ⇧⌘Z redoes.
  - **Mouse.** Click, shift-click, double and triple click, ⌥-click to add a
    caret, drag, and the wheel.
  - **Editing.** Clipboard and Cut, and IME input.
  - **Saving and closing.** Saving is atomic and keeps the file's permissions.
    Closing a tab or pane, Close Others/Below and Quit stop and warn about
    unsaved changes.
  - **Session restore.** Open editors come back at their cursor and scroll
    position.
  - **Control plane.** MTP reports each pane's kind; `pane.send`/`pane.run`
    insert text at the carets.
  - **Info.** The details panel and the status chip show the file, cursor,
    language and line ending.
- **Syntax highlighting in 80 languages.** These use built-in tree-sitter
  grammars that reparse incrementally after each edit and highlight only what
  is on screen. They cover Rust, Go, Python, TypeScript/TSX, C/C++, Java,
  C#, Kotlin, Swift, PHP, Ruby, shell and zsh, SQL, HTML/CSS/SCSS, Vue,
  Svelte, Dockerfile, Terraform, Nix, YAML/TOML/JSON, Protobuf, GraphQL and
  others; `.env`, `Dockerfile`, `CMakeLists.txt` and `#!` lines are
  recognised too.
- **Fallback highlighting.** Files that no tree-sitter grammar claims use
  Sublime syntaxes: syntect's default set, which covers OCaml, LaTeX, D,
  Pascal, Tcl, Graphviz and others, plus permissively licensed syntaxes from
  bat, such as Julia, Crystal, nginx, Apache config, VHDL, SystemVerilog,
  Odin, WGSL and Org. Licences are listed in `docs/third-party/SYNTAXES.md`.
- **Terminal contents come back after a relaunch.** As mtty quits, it saves
  each terminal's last 5,000 rows with their colours. Under vim or less, it
  saves the shell output beneath them. The restored pane shows those rows
  above its new shell and then deletes the saved file. The files are readable
  only by you; `restore-scrollback = false` or the setting in Settings turns
  this off.
- **Run it again.** If a program was running at quit (`vim notes.md`,
  `npm run dev`), the restored pane offers "Press Enter to run it again".
  Typing anything else drops the offer; nothing runs unasked. (macOS and
  Linux.)

## Fixes

- **Quitting from the Dock, logout, shutdown or AppleScript saved nothing.**
  These went through AppKit's quit, which ends the process at once; they now
  go through mtty's own Quit, which saves the session.
- **Trackpad scrolling barely moved.** Small pixel deltas were each rounded
  down to zero lines; they now add up, in terminals and editors.
- **The wheel did nothing in vim, less and man.** On the alternate screen it
  now sends arrow keys, as iTerm2, Ghostty and Alacritty do.

## Documentation

- mtty is now described as an AI-native terminal and editor in the README,
  `docs/PRODUCT.md` and mtty.dev.
- ADR 0034 (editor pane) is accepted, and milestones M5 to M7 are on the
  roadmap.
- The licence notice names the mtty authors.

## Verification

- Full CI on macOS, Linux and Windows, and the four-runner packaging, on the
  release commit.
- **New tests:**
  - the editor core, plus a 100 MB perf gate: opening takes 36 ms and a
    keystroke 0.0005 ms;
  - query compilation, file-type detection and highlighting for every built-in
    grammar;
  - every Sublime syntax parsing under the pure-Rust regex engine;
  - terminal snapshots: colours, reflow of wrapped lines, wide characters,
    and the shell under vim;
  - the private file permissions of saved contents.
- **Highlighting perf gate (Mac mini, release build):** the first parse of a
  1 MB file takes 64 ms, a keystroke reparse 3.5 ms, and highlighting one
  screen 0.09 ms.
- **Captured from the packaged macOS app:** a highlighted Julia file, and a
  relaunch after an AppleScript quit. The restored pane showed the colours,
  CJK text, reflowed lines and the vim offer.

## Known limits

- The app is larger: the macOS binary is about 88 MB, up from about 40 MB,
  because of the grammars.
- Highlighting stops for files over 1 MB until reparsing moves off the UI
  thread.
- Markdown, files over 64 MB and remote files still open in the floating
  editor.
- Typing, IME and ⌘S in the editor pane have not yet been checked by hand on
  every desktop.
- Terminal contents are saved only when mtty quits normally, so a crash
  loses them. Running programs do not survive a quit; that would need a
  separate PTY daemon.
- The "run it again" offer is not available on Windows.
- Builds are not notarized (macOS) or code-signed (Windows) yet.
