# mtty v0.0.14

[简体中文](v0.0.14.zh-CN.md)

Quicker session handling in the sidebar, modelled on Otty, and drops that
land where you release them.

## New

- **Close from the sidebar on hover.** The row under the pointer shows a
  close button where its shortcut was. It goes through the same close as
  the right-click menu, so an editor with unsaved changes still asks
  first. A lone session has no close button.
- **Hover shows where a session is.** A sidebar row's tooltip shows the
  terminal's folder (with home as `~`), the editor's file, or the ssh host,
  plus the full title when the row cuts it off.
- **Drop onto the sidebar opens a tab.** A dropped folder starts a new
  terminal in it. A dropped file opens in its own tab, in the editor or in
  view mode when it is large.
- **Middle click closes a tab in the tab bar**, as it already did in the
  sidebar.

## Fixes

- **Drops on macOS used the wrong position.** A file drag sends the window
  no pointer motion, so a drop was routed by wherever the pointer had last
  been before the drag. A drop on a terminal could open the editor, or the
  reverse. The drop point is now read from the system when the file lands.

## Verification

- Full CI on macOS, Linux and Windows, and the four-runner packaging, on the
  release commit.
- **New tests:**
  - hovering each sidebar row's right edge closes that row without
    switching to it; its middle switches; a lone session has no close;
  - home shown as `~`, without matching a partial prefix;
  - the drop pointer read through hand-declared CGPoint/CGRect encodings,
    which objc2 checks against the runtime's on the Mac mini (it read real
    screen coordinates there).
- **Not captured:** hovering and dropping in a real window. Moving the
  pointer or dragging needs accessibility access the build machine does
  not grant.

## Known limits

- Builds are not notarized (macOS) or code-signed (Windows) yet.
