# miaotty v0.0.2

[简体中文](v0.0.2.zh-CN.md)

## Changes

- Share the tab/session context menu across native and eframe, including marks,
  groups, Move Up/Down and Close Below.
- Draw native tab group dividers and persist marks/groups with sessions.
- Close Tab, tab × and session-row middle-click close the entire split tab;
  keyboard close retains focused-pane behavior and the last tab stays open.
- Preserve native tab focus when a background tab exits, with additional
  regression coverage.

## Downloads

- **macOS:** choose `miaotty-macos-arm64.zip` for Apple Silicon or
  `miaotty-macos-x86_64.zip` for Intel. Each contains both app bundles and the
  CLI.
- **Windows:** `miaotty-app-0.0.2-x86_64.msi`, or the portable zip.
- **Linux:** AppImage, `.deb`, or `.tar.gz` (x86_64).

## Verification and limitations

- All four release runner builds and assembly passed, including Linux package
  checks and Windows MSI install/URL registration/uninstall.
- Independently downloaded the published assets: all five manifest SHA-256
  values match; all nine minisign signatures verify against the committed public
  key. Both macOS architectures contain version 0.0.2 bundles with three
  binaries and icons, and pass strict ad-hoc signature verification.
- Local fmt, workspace clippy/tests, release performance gates and manifest
  tests passed.
- macOS builds are ad-hoc signed, **not Developer ID signed/notarized**. MSI has
  **no Authenticode signature**. Detached minisign signatures are provided
  separately.
- Windows IME, Linux/Wayland desktop interaction and real update self-replacement
  remain pending interactive acceptance; packaging success does not establish
  those behaviors.
