# mtty v0.2.0

[简体中文](v0.2.0.zh-CN.md)

## A new application icon

The application icon is now a transparent black line-art cat in a top hat,
replacing the terminal-arrow artwork. The macOS bundle icon (built from the
shared PNG) and the Windows window, taskbar and MSI icon (the shared ICO) both
use it. The ICO carries nine sizes from 16×16 through 256×256, all 32-bit with
alpha — including the 20 px and 40 px taskbar sizes — so the corners stay
transparent and small sizes stay crisp. An editable SVG source is committed
alongside the bitmap artwork. (#109, #110)

## Fixes

- CI: the `ci-gate` aggregate now requires the code jobs from the same flag that
  runs them, so an assets-only or scripts-only change no longer fails on jobs it
  intentionally skipped. (#111, #112)
- The Windows icon resource check accepts artwork with additional sizes, so the
  shared icon may carry extra taskbar sizes without failing packaging. (#113, #114)

## Verification

The source snapshot passes the workspace test suite, Clippy, formatting, and
privacy checks on CI, followed by the four-runner packaging and installer
checks (macOS both architectures, Linux AppImage/deb, Windows ZIP/MSI) with
detached minisign signatures. Apple Developer ID notarization and Windows
Authenticode signing remain dependent on owner credentials.
