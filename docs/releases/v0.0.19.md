# mtty v0.0.19

[简体中文](v0.0.19.zh-CN.md)

This patch fixes macOS shell startup and adaptive TUI input backgrounds.

- **macOS zsh loads the login environment.** New terminal panes start zsh as a
  login shell, loading the system PATH and user login profile. Commands such as
  Codex can find Node even when mtty starts from Finder with a minimal PATH.
  Existing shell integration remains active.
- **Adaptive TUI backgrounds use the terminal theme.** mtty answers OSC 10/11
  queries with its actual foreground and background colors. Codex can render
  its input and message backgrounds. Responses also reflect theme changes and
  work in byte-stream transport panes.

Verification runs on GitHub Actions: full workspace CI and performance gates,
followed by four-runner packaging and installer checks. No local build is needed.
