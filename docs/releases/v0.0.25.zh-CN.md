# mtty v0.0.25

- **Windows 不再乱码。** 每个 pane 的控制台改用 UTF-8 码页(cmd、PowerShell 与 Git Bash),
  不再走 `WriteConsoleW`、直接写 UTF-8 字节的程序(Bun,以及 miao 背后的原生 TUI 渲染器)
  不再把中日韩文字显示成乱码。
- **用系统默认程序打开(Open Externally)。** 新增命令(及“视图”菜单项),把当前编辑器的
  文件交给系统默认程序;终端 pane 回退到其所在目录。
- **跳转行高亮。** 跳转到行、跳转到符号、跳转到选区,以及 MTP 的 `app.edit`/`app.view`,
  都会让落点行闪烁一下。
- **kitty 键盘协议更完整。** 在消歧(disambiguate)之外,支持事件类型(含释放)与
  “所有键都以转义序列上报”。

验证在 GitHub Actions 上运行:完整的 workspace CI 与性能门禁,随后是四个 runner 的打包与安装器检查。

[完整变更](https://github.com/oxdingzg/miao-term/compare/v0.0.24...v0.0.25)
