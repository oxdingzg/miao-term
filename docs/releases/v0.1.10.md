# mtty v0.1.10

[简体中文](v0.1.10.zh-CN.md)

## Features

- **A default `views.json` on first start.** When `~/.config/mtty/views.json`
  does not exist, mtty now writes it at startup: empty rules, empty projects,
  and the worktree suffix enabled. A fresh install therefore has a rule file
  to edit instead of a silent fallback to raw program titles and the cwd
  folder name. An existing file — including a malformed one — is never
  overwritten, and the seeded rule set evaluates exactly like the missing
  file it replaces, so first-run behavior is unchanged. (#86)

## Documentation

- The view-rules guide (English and Simplified Chinese) mentions the
  first-start seed.

## Verification

The source snapshot passes the workspace test suite, Clippy, formatting, and
privacy checks on CI, followed by the four-runner packaging and installer
checks (macOS both architectures, Linux AppImage/deb, Windows ZIP/MSI) with
detached minisign signatures. Apple Developer ID notarization and Windows
Authenticode signing remain dependent on owner credentials.
