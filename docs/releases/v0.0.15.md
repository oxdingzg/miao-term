# mtty v0.0.15

A display fix on top of v0.0.14.

## Fixes

- **A dropped or pasted path was nearly invisible.** zsh highlights pasted
  text with inverse video. mtty drew the glyphs in the background colour, as
  inverse video asks, but painted the cell background from the cell's own
  colours, which for default colours means no background at all. The path
  showed as dark text on the dark terminal. Inverse cells now get the text
  colour as their background, so the path shows as dark on light.

## Verification

- Full CI on macOS, Linux and Windows, and the four-runner packaging, on the
  release commit.
- New tests check the background and text colours of default and coloured
  inverse cells.
- Captured from the packaged macOS app: a light band behind the pasted path.

See [v0.0.14](v0.0.14.md) for closing sessions from the sidebar on hover,
location tooltips and drops onto the sidebar.
