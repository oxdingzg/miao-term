# mtty v0.1.13

[简体中文](v0.1.13.zh-CN.md)

## Fixes

- **A live program title now outranks a project alias.** With `projects`
  configured in `views.json`, every tab under a project showed the bare
  project alias, so two tabs running different agents in the same repository
  looked identical even though each pane reported a distinct live OSC title.
  A non-empty live title now wins over the project alias whenever no rule
  template or rule alias pins the title. Explicit rule titles and rule aliases
  still win over everything, a pane that reports no title keeps the project
  alias and folder fallbacks, and `{alias}` templates keep rendering the
  project name. (#106)

## Verification

The source snapshot passes the workspace test suite, Clippy, formatting, and
privacy checks on CI, followed by the four-runner packaging and installer
checks (macOS both architectures, Linux AppImage/deb, Windows ZIP/MSI) with
detached minisign signatures. Apple Developer ID notarization and Windows
Authenticode signing remain dependent on owner credentials.
