# mtty v0.0.24

- **Tab badges follow `[badges]`.** The `processing`, `idle`, `awaiting` and
  `error` switches now decide which agent states show on tabs. A state switched
  off shows its tab as a plain terminal: no state circle and no finished or `!`
  mark. System notifications are unaffected; all four stay on by default.
- **Quitting with `keep-sessions-on-quit` verified on Windows.** Both the Quit
  command and closing the window leave a running program in its PTY host, and
  the next launch reattaches it.

Verification runs on GitHub Actions: full workspace CI and performance gates,
followed by four-runner packaging and installer checks.
