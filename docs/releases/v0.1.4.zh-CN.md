# mtty v0.1.4

[English](v0.1.4.md)

## 修复与改进

- **终端关闭不再阻塞界面。** 子进程终止与回收移到后台线程。Unix shell 即使忽略
  SIGHUP 也会被强制终止；Windows 进程树终止同样在后台执行。
- **有磁盘限额的资源诊断。** 后台每 30 秒记录进程 CPU、RSS 和渲染活动。
  资源日志总量上限为 64 MiB，崩溃日志含备份上限为 2 MiB。
  设置 `MTTY_MONITOR=0` 可关闭采样。见[故障排查](../TROUBLESHOOTING.zh-CN.md)。
- **Windows 更新事务。** ZIP 更新先验证并暂存三个可执行文件，再保留备份并替换，
  失败时回滚。MSI 返回码也会检查。ZIP 解压使用 .NET Unicode 路径，英文版 Windows
  上的中文安装路径也可正常处理。见 [ADR 0043](../decisions/0043-windows-update-transaction.zh-CN.md)。
- **Agent 编辑与 ACP。** 提案中被删除的行保留供审阅，不会进入复制或保存内容；
  整文件提案保留未变动的上下文。ACP 补齐认证、会话加载与终端回调；
  客户端写文件需审阅并保存，执行命令需授权，输出与进程数量均有上限。
- **剪贴板与传输。** Windows/X11 剪贴板图片支持 PNG 编码及文本粘贴清理，
  Wayland 使用宿主已有的 data device。串口空闲读取超时或中断时重试；
  关闭 pane 会停止其空闲字节流读取线程。
- 更新文档及第三方许可证声明。

## 验证

源码快照在远程构建机通过 macOS 工作区 531 项测试、Clippy、格式、隐私检查及
14 项 release 性能门禁；Windows 实机三项 ConPTY 测试通过。
发布流水线另检查 macOS 两种架构、Linux AppImage/deb、Windows ZIP/MSI 打包、
安装包内容及 minisign 分离签名。

更多平台验收证据与边界见[验收记录](../ACCEPTANCE.zh-CN.md)。
Apple Developer ID 公证和 Windows Authenticode 签名仍需所有者凭证；
minisign 分离签名单独提供。Claude ACP 实际提示仍需提供商认证。
