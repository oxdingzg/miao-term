# mtty v0.0.19

本次补丁修复 macOS shell 启动环境及 TUI 自适应输入框背景。

- **macOS zsh 加载登录环境。** 新终端面板以登录模式启动 zsh，加载系统 PATH
  与用户登录配置。即使从 Finder 启动 mtty，Codex 等命令也能找到 Node。
  原有 shell 集成功能继续生效。
- **TUI 自适应背景使用终端主题。** mtty 通过 OSC 10/11 返回实际前景色和背景色，
  让 Codex 正常绘制输入框与消息底色。响应随主题切换更新，也支持字节流连接面板。

验证在 GitHub Actions 上执行：完整 workspace CI 与性能门禁，以及四 runner 打包和
安装包检查。本机无需编译。

[完整变更](https://github.com/oxdingzg/mtty/compare/v0.0.18...v0.0.19)
