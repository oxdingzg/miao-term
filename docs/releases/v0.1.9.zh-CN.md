# mtty v0.1.9

[English](v0.1.9.md)

## 新特性

- **私有管道 miao 控制通道。** mtty 可以通过类型化的私有管道对接 `miao runtime access`,
  管理既有 miao Runtime——连接状态、会话上下文、邀请、精确密钥批准与拒绝、版本协商——
  无需把凭据经过终端窗格传递,也不缓存管理员凭据。
- **按窗格的 miao runtime 上下文。** 共享的 miao Runtime 不再把首个启动它的窗格当作
  所有后续客户端的身份:`mtty-cli state --runtime-context FILE|-` 让每个客户端上报自己的
  Runtime/存储绑定(或显式的已附着服务端标记),退出时清除。

## 修复

- **以受支持的参数恢复 miao 会话。** Resume Agent 动作此前传的是 miao 不支持的 `--resume`;
  现在改用 `--session`,同时保留会话标识校验。
- **TUI 帧不再停滞或丢格。** 同步帧在生产者停滞时可能一直滞留在缓冲区;现在会处理 VT 解析器的
  过期时限,并在该时限唤醒事件循环。停滞的重绘在多次 flush 间保留 TUI 网格格子,不再丢弃。

## 验证

源码快照通过工作区测试、Clippy、格式化与隐私检查的 CI 验证,随后是四平台打包与安装器检查
(macOS 双架构、Linux AppImage/deb、Windows ZIP/MSI)及分离的 minisign 签名。
Apple Developer ID 公证与 Windows Authenticode 签名仍依赖所有者凭据。
