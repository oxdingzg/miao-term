# mtty v0.0.9

本版本包括:按代码核对功能表时发现的问题的修复、"软件更新"窗口撑满整个窗口的修复、Edit in Tab,以及崩溃日志。

## 修复

- **"软件更新"窗口撑满整个窗口高度。** 对话框从窗口顶部延伸到底部,标题被顶出屏幕,按钮浮在中间。原因是按钮行占用了
  屏幕剩余的全部高度;现在它只占一行。其他对话框也按同样的问题逐一核对过。
- **文档旁边的 Markdown 图片不显示。** 预览中 `![x](img/a.png)` 这样的相对路径从未加载;现在按文档所在目录解析。
  绝对路径照常可用;远端文档不受影响。
- **View 规则无法按文件匹配。** 带 `file` 条件的 `views.json` 规则从不生效,标题中的 `{file}` 始终为空。现在文件取前台
  程序打开的那个(`vim src/main.rs` 中的 `src/main.rs`),支持 macOS 与 Linux。
- **Agent 面板中文化。** Agent 页的 `agent`、`tty` 字段名和状态值(处理中、空闲、等待你、出错)此前仍是英文。

## 新增

- **Edit in Tab。** 内置编辑器为本地文件提供"在标签中编辑"按钮:按 ADR 0017 的设计,新开一个标签运行配置项 `editor`,
  否则 `$EDITOR`,否则 `vi`(Windows 上为记事本)。有未保存修改时按钮不可用,因为外部编辑器读取的是磁盘上的文件。
- **崩溃日志。** 程序 panic 时会把消息、位置和调用栈追加到 `~/Library/Logs/mtty/panic.log`(Linux 为
  `~/.local/state/mtty`,Windows 为 `%LOCALAPPDATA%\mtty\logs`);macOS 应用的 stderr 会被丢弃,此前崩溃不留任何痕迹。

## 文档

- `docs/PRODUCT.zh-CN.md` 的功能表按代码逐行重新核对:早先批次已修复的问题不再列出;实际并不存在的 agent Resume 与
  配额显示改列为"尚未设计"。

## 验证

- 发布提交上完整的 macOS、Linux、Windows CI,以及四个 runner 的打包。
- 新增测试:更新对话框的高度(旧布局下会失败)、经 egui 文件加载器加载的相对与绝对路径 Markdown 图片(没有 vendored 补丁时
  绝对路径用例会失败)、从真实 `tail -f` 取得的前台程序文件、Edit in Tab 的命令,以及中文 Agent 行。
- 在打包好的 macOS 应用中截图核对了"软件更新"对话框。

## 已知限制

- 构建尚未经过 macOS 公证或 Windows 代码签名。
- View 规则的 `file` 匹配在 Windows 上不可用。
- mosh 只验证了命令构造;AppImage 与 Windows 的安装并重启辅助脚本有单元测试,但尚未在这两类桌面上实际运行。
