# mtty v0.0.14

侧边栏的会话操作更顺手了;拖放文件时,也会落在你松开鼠标的位置。

## 新增

- **悬停即可从侧边栏关闭会话。** 鼠标停在哪一行,该行右侧原来显示快捷键的位置就换成关闭按钮。它与右键菜单里的关闭走同一流程,
  所以有未保存修改的编辑器仍会先询问。只剩一个会话时不显示关闭按钮。
- **悬停显示会话所在位置。** 侧边栏某一行的提示会显示终端所在的文件夹(家目录显示为 `~`)、编辑器打开的文件,或 SSH 主机;
  标题被截断时,还会显示完整标题。
- **拖到侧边栏即新建标签。** 拖入文件夹,会在该文件夹中新开一个终端;拖入文件,会在新标签中打开:在编辑器中打开,
  文件较大时则以只读查看模式打开。
- **在标签栏中用鼠标中键关闭标签**,与侧边栏一致。

## 修复

- **macOS 上拖放的位置不对。** 拖动文件时窗口收不到鼠标移动,于是拖放按拖动开始前鼠标最后所在的位置来判断:拖到终端上可能
  打开了编辑器,反之亦然。现在会在文件放下的那一刻向系统读取鼠标位置。

## 验证

- 发布提交在 macOS、Linux、Windows 上跑完整 CI,并完成四个 runner 的打包。
- **新增测试**:
  - 鼠标停在侧边栏每一行的右侧并点击,会关闭该行,且不会切换过去;点击行的中间则切换过去;只剩一个会话时没有关闭按钮;
  - 家目录显示为 `~`,且不会误匹配只是前缀相同的路径;
  - 拖放位置通过手写的 CGPoint/CGRect 编码读取;objc2 在 Mac mini 上会把它们与运行时的编码比对,在那台机器上读到了真实的
    屏幕坐标。
- **未截图验证**:在真实窗口中悬停和拖放。移动鼠标或拖动需要辅助功能权限,构建机器没有授予。
