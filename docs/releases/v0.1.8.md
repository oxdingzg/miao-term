# mtty v0.1.8

[简体中文](v0.1.8.zh-CN.md)

## Fixes

- **Tab titles survive a restart.** A tab that was never renamed shows an
  automatic title — the pane's OSC program name, then the current folder, then
  `shell N`. That title was not stored in the session, so after a restart the
  fresh shell's title replaced it and tabs came back as the running program's
  name instead of the title they had before. The displayed title is now saved
  and restored, so a restart shows the same title; a tab you renamed still keeps
  your chosen name.

## Verification

The source snapshot passes the workspace test suite, Clippy, formatting, and
privacy checks on CI, followed by the four-runner packaging and installer
checks (macOS both architectures, Linux AppImage/deb, Windows ZIP/MSI) with
detached minisign signatures. The title precedence is covered by a unit test.
Apple Developer ID notarization and Windows Authenticode signing remain
dependent on owner credentials.
