# v0.1.12

[English](v0.1.12.md)

## 单画面 Markdown 写作

Markdown 默认在一个写作窗格中打开。点击渲染块即可在原位置编辑源码，或切换 **Source / 源码** 编辑完整文档。撤销、重做和 `⌘S`/`Ctrl+S` 保留现有文档、历史及保存链路。回归测试覆盖中文、emoji 和外部修改；只读模式禁止原地修改；独立预览窗格仍可按需开启。

本次完成 [#94](https://github.com/oxdingzg/mtty/issues/94) 的第一阶段：块级原地编辑。逐 token 显示源码、高级表格及完整写作路线图继续在该 issue 跟踪。

## 终端与输入修复

- 主屏幕与备用屏幕切换时清除对应窗格的选区，防止 shell 中的高亮残留到全屏 TUI 上。
- Home/End、Ctrl+Home/Ctrl+End 映射为行编辑器和 TUI 所需的终端序列。
- 共享 shell 集成脚本改为原子发布，防止并发启动窗格时读取到被截断的脚本，导致命令、输出和目录跟踪失效。

## 验证与分发

远程工作区测试、Clippy 和 Release 性能门禁通过；隔离状态的应用截图验证了 Markdown 新布局。发布流程构建两个 macOS 架构、Linux 和 Windows，并检查 Linux 包内容及 Windows MSI 的安装、卸载。本轮未执行原生桌面 IME 自动化验证。

源码检查按改动范围触发，`ci-gate` 仍要求所有适用检查通过。分发包继续包含 CLI、PTY host、许可证和更新清单。
