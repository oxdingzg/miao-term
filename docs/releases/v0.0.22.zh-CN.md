# mtty v0.0.22

pane 里的程序现在能挺过更新,agent 标签的状态也一眼可见。

- **程序挺过更新、重启和崩溃。** 每个本地 shell 运行在自己的 PTY 宿主(`mtty-ptyhost`,ADR 0041)中:*Update and Relaunch*、新增的 *重启 mtty(保留运行中的程序)* 命令以及崩溃,都不会再结束 pane 里的 Claude Code、miao 或其他程序。重启后的 mtty 会重新接上,精确重建每块屏幕,只回放期间新产生的输出。macOS、Linux、Windows 上默认开启(`pty-host = false` 可关闭)。普通退出仍会结束程序,除非设置 `keep-sessions-on-quit = true`;保留的程序最多等待 `detached-timeout`(默认 `24h`)。崩溃留下的程序会在命令面板中提供"接回"或"结束"。
  升级*到*本版本的那次更新仍由没有宿主的 v0.0.20 执行,所以保护从再下一次更新开始。
- **标签上的 agent 状态。** agent 标签的图标是一个圆:处理中为半圆;完成且你还没处理为实心(绿);等待你输入或出错为实心黄/红并带 `!`;其余为空心圆。正在看的标签上,完成标记也会保留,直到你在其中输入。
- **拖入文件。** 把文件拖到终端上会显示两个落点:插入转义好的路径;或在 pane 底部的条带上改为打开(文件在编辑器中打开,文件夹在该目录开一个新终端)。按住 Option/Alt 互换。
- **显示修复。** Claude Code 的 `⏺` 等符号按终端颜色绘制,不再画成彩色 emoji;暗淡文字(SGR 2,例如 Claude Code 的建议提示词)会变暗显示。
- **回滚位置保持。** 往上翻看历史时,agent 刷新 spinner 不再把视图拉回底部。
- **Windows。** 语言服务器、ACP agent 和后台工具不再闪出控制台窗口;工具按可执行扩展名解析;终端查询回复能正确送达。
- **许可证。** 每个产物都附带第三方许可证,CI 会按许可证和安全公告检查依赖。

v0.0.21 打了 tag 但未发布:它的发布任务停在一个尚不认识 `mtty-ptyhost` 的打包测试上。本版本即 v0.0.21 加上该修复。

验证在 GitHub Actions 上运行:完整的 workspace CI 与性能门禁(新增 PTY 宿主的回显延迟和输出吞吐),随后是四个 runner 的打包与安装器检查。
