# mtty v0.0.11

[简体中文](v0.0.11.zh-CN.md)

A crash fix on top of v0.0.10.

## Fixes

- **Hovering below a terminal's last row crashed mtty.** Link detection maps
  the pointer to a terminal row. In the strip of padding under the last row,
  that row is past the screen, and reading it went out of bounds. This was
  seen twice in v0.0.9's crash log, both times under a full-screen program.
  Cells outside the screen now read as blank. A related bug is also gone:
  when scrolled back, the padding no longer picked up another row's text as
  a link.

## Verification

- Full CI on macOS, Linux and Windows, and the four-runner packaging, on the
  release commit.
- A new test reads rows past the screen, with the view scrolled back. It fails
  on the old code.

See [v0.0.10](v0.0.10.md) for the editor pane, syntax highlighting and
restored terminal contents.
