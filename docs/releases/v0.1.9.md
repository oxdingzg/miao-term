# mtty v0.1.9

[简体中文](v0.1.9.zh-CN.md)

## Features

- **Private-pipe miao control transport.** mtty can administer an existing miao
  Runtime over a typed private pipe to `miao runtime access` — connection
  status, session context, invitations, exact-key approval and rejection, and
  version negotiation — without sending credentials through a terminal pane or
  caching the administrator credential.
- **Per-pane miao runtime context.** A shared miao Runtime no longer treats the
  pane that first launched it as the identity of every later client:
  `mtty-cli state --runtime-context FILE|-` lets each client report its own
  Runtime/storage binding (or an explicit attached-server marker) and clears
  it on exit.

## Fixes

- **Resume miao with the supported session option.** The Resume Agent action
  passed `--resume`, which miao does not support; resuming now uses `--session`
  while retaining session identifier validation.
- **TUI frames no longer stall or lose cells.** A synchronized frame could
  stay buffered indefinitely after its producer stalled; the VT parser's
  expiry deadline is now serviced and the event loop wakes at that deadline.
  Stalled redraws also preserve the TUI grid cells across flushes instead of
  dropping them.

## Verification

The source snapshot passes the workspace test suite, Clippy, formatting, and
privacy checks on CI, followed by the four-runner packaging and installer
checks (macOS both architectures, Linux AppImage/deb, Windows ZIP/MSI) with
detached minisign signatures. Apple Developer ID notarization and Windows
Authenticode signing remain dependent on owner credentials.
