# mtty v0.0.18

[简体中文](v0.0.18.zh-CN.md)

This patch preserves TUI surface colors and corrects the sidebar controls.

- **TUI borders keep their original colors.** Box-drawing and block characters
  bypass text contrast enhancement. In miao, the input panel's dark half-cell
  bottom edge now blends into the panel instead of appearing as a gray stripe.
  Ordinary text keeps its contrast enhancement.
- **Sidebar buttons match their panel positions.** The left and right sidebar
  toggles now use the corresponding icons and order.
- **ACP tests run on every platform.** The fake-agent transport uses loopback
  TCP instead of Unix-only sockets, preserving round-trip coverage on Windows.

Verification runs on GitHub Actions: full workspace CI and performance gates,
followed by four-runner packaging and installer checks. No local build is needed.
