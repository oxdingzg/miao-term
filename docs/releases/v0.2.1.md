# mtty v0.2.1

[简体中文](v0.2.1.zh-CN.md)

## Agent task states that match the work

Agent tabs now support explicit task outcomes, separate from whether an agent is
currently executing. A busy circle means execution, a green full circle means
explicit completion, an amber empty ring means paused unfinished work or unknown
status, and waiting circles distinguish user decisions from background work.
For miao, becoming idle no longer creates completion attention. Other agents that
only report busy and idle retain their existing behavior. (#121)

Queued prompts are delivered when an agent enters a ready state, including
completed or paused unfinished work. They stay queued during background waits,
unknown status and pending decisions. Moving between ready states does not deliver
an extra prompt. Existing badge preferences also apply to the new states. (#121)

The full coordination between tab badges, the todo sidebar and Session activity
requires a miao build containing [miao #583](https://github.com/oxdingzg/miao/pull/583).
Updating mtty alone does not add those observations to an older miao client.

## Packages

The release pipeline checks macOS packages for both architectures, Linux
AppImage/deb packages, and Windows ZIP/MSI packages, including MSI installation
and uninstallation. It validates the update manifest and configured detached
signatures before publishing.
