# mtty v0.1.11

[简体中文](v0.1.11.zh-CN.md)

## Fixes

- **Tab titles no longer freeze after a restart.** The title a session was
  saved with held a restored tab forever: it was preferred over every
  automatic title and never cleared, and each save wrote it back, so a tab
  kept its pre-restart name across `cd`, agents and program titles, and the
  view rule engine (ADR 0007) never applied to it again (#88). The saved
  title now holds the tab's place only until the pane reports live context —
  its working directory or a program title — then view rules, the program
  title and the folder take over again (#89). A restart still shows the
  previous title first, before the pane reports.

## Verification

The source snapshot passes the workspace test suite, Clippy, formatting, and
privacy checks on CI, followed by the four-runner packaging and installer
checks (macOS both architectures, Linux AppImage/deb, Windows ZIP/MSI) with
detached minisign signatures. Apple Developer ID notarization and Windows
Authenticode signing remain dependent on owner credentials.
