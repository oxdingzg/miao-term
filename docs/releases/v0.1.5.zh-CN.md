# mtty v0.1.5

[English](v0.1.5.md)

## 新功能

- **主题与界面。** 新增可选的 **mtty** 预设（藏青窗口与界面，
  `#171b24`/`#212733`/`#2b333e`），与 Nord（默认）、Dracula、Gruvbox 并列。
  文件树增加按类型着色的图标（文件夹、代码、文档、配置、锁、数据库）；
  **新建 SSH 会话**表单重构为快速连接、已保存主机字段、高级选项，
  以及「连接 / 保存并连接」操作。见 [CONFIG.zh-CN.md](../CONFIG.zh-CN.md)。
- **Agent 标签标记。** 标签标记现在能区分「运行中」与空闲、等待：
  空闲是空心圆环，执行中是旋转的强调色圆弧（带动画，长回合不会显得卡死），
  等待是带实心内核的圆环，与已完成的实心圆点区分开。
- **启动检查更新。** mtty 在启动时检查一次新版本（配置项
  `update-auto-check`，默认开启），并在状态栏显示。设为
  `update-auto-check = false` 可让它在你不主动检查前不发起请求。

## 修复

- **macOS 标签拖拽。** 透明且铺满的标题栏会让 macOS 在标题区任意按下时启动
  窗口拖动，导致拖动标签时移动整个窗口、而非重排标签。现在关闭窗口的系统拖动，
  由应用保留自己基于区域的拖拽。
- **编辑器行号 gutter 下溢。** 大文件窗口化视图可能把行号宽度从 gutter 中
  减到负数——debug 构建会在绘制回调中 panic（进而中止进程），release 构建会
  回绕成错误偏移。现改为钳制到最后几格，并按字符计数，避免拆开折叠标记。

## 杂项与文档

- 为受保护的 `main` 引入 PR 工作流（CI、squash 合并、约定式标题），
  含 CODEOWNERS、PR 模板与规范检查。
- `scripts/session-worktree.sh` 用一次性 git worktree 隔离并行会话，
  规则记录在 AGENTS.md。
- 新增应用托管的 SSH 隧道生命周期提案，并刷新 CI 性能基线。

源码快照在 CI 通过工作区测试、Clippy、格式与隐私检查，随后是四平台打包与

签名仍需所有者凭证；Claude ACP 实际提示仍需提供商认证。
