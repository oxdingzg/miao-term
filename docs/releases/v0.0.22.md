# mtty v0.0.22

Programs in your panes now keep running through updates, and agent tabs show
their state at a glance.

- **Programs survive updates, relaunches and crashes.** Each local shell runs
  in its own PTY host (`mtty-ptyhost`, ADR 0041), so *Update and Relaunch*, the
  new *Relaunch, Keeping Programs Running* command and a crash no longer end
  Claude Code, miao or anything else running in a pane: the relaunched mtty
  reattaches, rebuilds each screen exactly and replays only what was printed
  meanwhile. On by default (`pty-host = false` turns it off) on macOS, Linux and
  Windows. An ordinary quit still ends the programs unless
  `keep-sessions-on-quit = true`; a kept program waits `detached-timeout`
  (default `24h`) for mtty to return. Programs left by a crash are offered in
  the command palette to reattach or end.
  The update *to* this version is still performed by v0.0.20, which has no
  hosts: protection starts with the update after it.
- **Agent state on tabs.** An agent's tab icon is a circle: half while
  working, full when it finished and you have not acted on it yet (green), full
  amber or red with `!` when it waits for you or failed, an empty ring
  otherwise. The finished mark now stays on the tab you are looking at until
  you type there.
- **Dropping files.** A file dragged over a terminal shows two targets:
  inserting its shell-quoted path, or, on a band along the pane's bottom,
  opening it (files in the editor, a folder as a terminal there). Option/Alt
  swaps them.
- **Display fixes.** Claude Code's `⏺` markers and similar symbols take the
  terminal colour instead of drawing as colour emoji, and faint text (SGR 2,
  such as Claude Code's suggested prompt) is drawn dimmed.
- **Scrollback stays put.** A pane scrolled back is no longer pulled to the
  bottom while an agent redraws its spinner.
- **Windows.** Language servers, ACP agents and background tools no longer
  flash console windows, tools resolve with their executable extensions, and
  terminal query replies are delivered.
- **Licences.** Every artifact carries the third-party licences, and CI gates
  dependencies on licences and advisories.

v0.0.21 was tagged but never published: its release job stopped on a
packaging test that did not yet know about `mtty-ptyhost`. This release is
v0.0.21 plus that fix.

Verification runs on GitHub Actions: full workspace CI and performance gates
(now including a PTY host's echo latency and output throughput), followed by
four-runner packaging and installer checks.
