# mtty v0.0.11

在 v0.0.10 基础上修复一个崩溃。

## 修复

- **鼠标停在终端最后一行下方时 mtty 崩溃。** 链接检测会把鼠标位置换算成终端的行;在最后一行下方那条内边距里,换算出的
  行已经超出屏幕,读取时越界。v0.0.9 的崩溃日志里记录了两次,都发生在全屏程序下。现在屏幕外的格子一律当作空白;
  顺带修复了一个相关问题:往上滚动时,内边距不再把别的行的文字当成链接。

## 验证

- 发布提交在 macOS、Linux、Windows 上跑完整 CI,并完成四个 runner 的打包。
- 新增测试:在往上滚动的状态下读取屏幕之外的行;旧代码会失败。

编辑器 pane、语法高亮和终端内容恢复见 [v0.0.10](v0.0.10.zh-CN.md)。
