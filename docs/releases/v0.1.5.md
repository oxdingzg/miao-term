# mtty v0.1.5

[简体中文](v0.1.5.zh-CN.md)

## Features

- **Themes and chrome.** A selectable **mtty** preset (navy window and
  chrome, `#171b24`/`#212733`/`#2b333e`) joins Nord (default), Dracula and
  Gruvbox. The file tree gains per-type colored icons (folder, code, doc,
  config, lock, database), and the **New SSH Session** form is reworked into
  quick-connect, saved-host fields, an Advanced section, and
  Connect / Save & Connect actions. See [CONFIG.md](../CONFIG.md).
- **Agent tab markers.** The tab marker now distinguishes a running turn from
  idle and waiting: idle is an empty ring, executing is a rotating accent arc
  (animated, so a long turn never looks stalled), and waiting is a ring with a
  solid core apart from the finished disc.
- **Startup update check.** mtty checks for a newer release once at launch
  (config `update-auto-check`, on by default) and shows it in the status line.
  Set `update-auto-check = false` to make no request until you ask.

## Fixes

- **macOS tab dragging.** The transparent, full-size title bar made macOS start
  a window drag on any press in the title strip, so dragging a tab chip moved
  the whole window instead of reordering tabs. System drag is now off for the
  window and the app keeps its own region-based dragging.
- **Editor gutter underflow.** A windowed large-file view could subtract the
  line number's width from the gutter below zero — a debug build panicked
  inside the draw callback, a release build wrapped to a garbage offset. The
  last cells are clamped instead, counted by character so a fold marker is
  never split.

## Chores and documentation

- A pull-request workflow for the protected `main` (CI, squash merge,
  conventional titles), with CODEOWNERS, a PR template and a standards check.
- `scripts/session-worktree.sh` to isolate parallel sessions in disposable git
  worktrees, documented in AGENTS.md.
- An app-managed SSH tunnel lifecycle proposal, and refreshed CI performance
  baseline.

## Verification

The source snapshot passes the workspace test suite, Clippy, formatting, and
privacy checks on CI, followed by the four-runner packaging and installer
checks (macOS both architectures, Linux AppImage/deb, Windows ZIP/MSI) with
detached minisign signatures. Apple Developer ID notarization and Windows
Authenticode signing remain dependent on owner credentials; Claude ACP still
needs provider authentication for a real prompt.
