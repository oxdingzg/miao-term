# miaotty v0.0.2

## 更新内容

- native 与 eframe 的标签栏、会话侧栏共用右键菜单，支持标记、分组、上移/下移及关闭下方标签。
- native 显示分组分隔线，标记与分组随会话保存和恢复。
- “关闭标签”、标签 × 与会话行中键关闭整个分屏标签；键盘关闭仍保留当前窗格行为，最后一个标签保持打开。
- 修复 native 后台标签退出后焦点可能跳转的问题，并补齐相关回归测试。

## 下载

- **macOS：** Apple Silicon 选择 `miaotty-macos-arm64.zip`，Intel 选择 `miaotty-macos-x86_64.zip`。每个包都包含两个 app bundle 和 CLI。
- **Windows：** `miaotty-app-0.0.2-x86_64.msi`，或便携 zip。
- **Linux：** AppImage、`.deb` 或 `.tar.gz`（x86_64）。

## 验证与限制

- 四个 release runner 构建与汇总全部通过，包括 Linux 包检查以及 Windows MSI 安装/URL 注册/卸载。
- 独立下载已发布产物：五个清单 SHA-256 全部匹配；九个 minisign 签名均通过已提交公钥校验。两个 macOS 架构都包含 0.0.2 版本的 bundle（三个二进制和图标），并通过严格 ad-hoc 签名校验。
- 本机 fmt、workspace clippy/测试、release 性能门禁与清单测试全部通过。
- macOS 构建为 ad-hoc 签名，**并非 Developer ID 签名/公证**。MSI **没有 Authenticode 签名**。分离的 minisign 签名单独提供。
- Windows IME、Linux/Wayland 桌面交互与真实更新自替换仍待交互式验收；打包成功不代表这些行为已验证。
