# mtty v0.0.20

Windows uses the same application artwork as macOS and gains installation shortcuts.

- **Executable and runtime icons.** The Windows executable embeds the mtty
  icon in seven sizes, from 16 to 256 pixels. Window and taskbar icons load
  that resource instead of the Windows default icon.
- **Installer application icon.** The MSI uses the same icon for the installed
  application entry in Windows settings.
- **Visible launch entries.** The MSI creates mtty shortcuts in the Start menu
  and on the desktop, both with the application icon. Uninstall removes them.
- **Packaging verification.** Windows CI compares all embedded icon frames
  with the shared icon asset before packaging and after MSI installation,
  and checks the installed application's icon registration and shortcut targets.

- **Compact Windows header.** Tabs, a compact application menu and window
  controls share one row. Dragging, double-click to maximize and edge resizing
  remain available.
- **Cursor query ordering.** Queries flush pending synchronized terminal output
  before reporting the cursor, so TUIs receive the current position.

Verification runs on GitHub Actions: full workspace CI and performance gates,
followed by four-runner packaging and installer checks. No local build is needed.
