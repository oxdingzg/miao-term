# mtty v0.2.1

[English](v0.2.1.md)

## 与实际工作一致的 Agent 任务状态

Agent tab 现在支持明确的任务结果，与“当前是否正在执行”分别表达。忙碌圆圈表示
正在执行，绿色实心圆表示明确完成，黄色空心圆表示未完成暂停或状态未知，等待圆圈
区分等待用户决定与等待后台工作。对于 miao，进入 idle 不再自动产生“完成”提醒；
仅上报忙碌与空闲的其他 Agent 保留原有行为。（#121）

Agent 进入可接收新输入的状态时，包括完成或未完成暂停，排队提示才会投递。等待
后台工作、状态未知、等待用户决定时，提示继续留在队列中；在不同可接收状态之间
切换不会重复投递。现有圆圈显示偏好也适用于新增状态。（#121）

tab 圆圈、右侧 todo 和 Session 活动的完整协同需要使用包含
[miao #583](https://github.com/oxdingzg/miao/pull/583) 的 miao 构建。
仅更新 mtty 不会让旧版 miao 客户端具备这些观测能力。
