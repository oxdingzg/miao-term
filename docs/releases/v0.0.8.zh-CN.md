# mtty v0.0.8

这是一个调整窗口布局的版本(参照 Otty),同时修复了编辑器与 Markdown 预览中的两个问题。

## 改动

- **会话侧栏占满窗口高度。** 会话列表从窗口顶部一直延伸到底部,顶部放 `+`(新建标签)和收起侧栏按钮。可以拖动会话行
  重排标签,标签分组变化处显示分隔线。
- **标题行取代横向标签栏。** 侧栏顶部旁边的一行居中显示当前标签的标题,面板与字号按钮(详情、侧栏、A-、A+)位于右上角。
  收起侧栏时,这一行重新显示内联标签栏(`+`、`×`、拖拽重排)。
- **macOS:透明标题栏。** 安装的应用中,内容延伸到标题栏下方,红绿灯位于侧栏顶部。标题行的空白处可以拖动窗口,双击缩放。
  自绘菜单的裸跑 `mtty` 二进制保留标准标题栏。

## 修复

- **浮动窗口从角落只能单向缩放。** 拖动编辑器(以及设置、主机等其他浮动窗口)的右下角时,只有宽度或只有高度会变。
  egui 0.30 在重叠的拖动区域之间优先选择更细的那个,所以边总是胜过角;现在角会优先响应。
- **Markdown 表格截断长单元格。** Markdown 预览中,较长的表格单元格在窗口边缘被截断,滚动也看不到其余内容。现在单元格会在
  预览宽度内换行(修补了 `egui_commonmark`,见 `vendor/egui_commonmark/PATCHES.miao.md`)。
- **macOS:终端上方有一条空白。** 应用为一个并未绘制的窗口内菜单预留了高度;现在终端紧接在标题行下方。

## 验证

- 发布提交上完整的 macOS、Linux、Windows CI,以及四个 runner 的打包。
- 新布局的回放测试(终端区域与宿主的网格一致、标题行拖动区域、会话行拖拽重排、分组分隔线),以及角落缩放与表格换行的测试;
  后两者在没有修复时会失败。
- 用这些提交构建的 macOS 应用在 Mac mini 上截图核对,新布局(侧栏与红绿灯、右上角按钮)在一台 MacBook 桌面上核对过。
  角落缩放与表格换行由上述测试覆盖。

## 已知限制

- 构建尚未经过 macOS 公证或 Windows 代码签名。
- 新布局只在 macOS 真实桌面上核对过;Linux 与 Windows 上由回放测试覆盖。
- mosh 只验证了命令构造;AppImage 与 Windows 的安装并重启辅助脚本有单元测试,但尚未在这两类桌面上实际运行。
