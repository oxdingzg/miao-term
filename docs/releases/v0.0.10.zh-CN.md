# mtty v0.0.10

本版本首次加入编辑器 pane(ADR 0034),语法高亮支持 80 种语言,更多语言有兜底高亮;重新打开 mtty 时,终端内容也会回来。

## 新增

- **编辑器 pane。** 本地非 Markdown 文件不再用浮动窗口打开,而是在标签里、与终端并排的编辑器 pane 中打开,可以像终端一样分屏。
  - **绘制**:文字经终端渲染器绘制,包括行号、当前行、选区与光标,超长行在 pane 边缘裁剪。
  - **键盘**:沿用 macOS 文本编辑习惯(Linux/Windows 上用 Ctrl)。编辑器获得焦点时,它的快捷键优先于应用快捷键:⌘D 选中下一处,⇧⌘Z 重做。
  - **鼠标**:单击、Shift 单击、双击/三击、⌥ 单击添加光标、拖选、滚轮。
  - **编辑**:剪贴板与剪切,以及输入法输入。
  - **保存与关闭**:原子保存,保留文件权限;关闭标签或 pane、关闭其他/下方、退出时,有未保存修改都会拦下并提示。
  - **会话恢复**:已打开的编辑器会回到原来的光标和滚动位置。
  - **控制面**:MTP 会报告每个 pane 的类型;`pane.send`/`pane.run` 在光标处插入文本。
  - **信息**:详情面板与状态栏显示文件、光标、语言和换行符。
- **80 种语言的语法高亮。** 使用内置 tree-sitter 语法,每次编辑后增量重新解析,只高亮屏幕上的内容。覆盖 Rust、Go、Python、TypeScript/TSX、C/C++、Java、C#、Kotlin、Swift、PHP、Ruby、shell 与 zsh、SQL、HTML/CSS/SCSS、Vue、Svelte、Dockerfile、Terraform、Nix、YAML/TOML/JSON、Protobuf、GraphQL 等;`.env`、`Dockerfile`、`CMakeLists.txt` 和 `#!` 首行也能识别。
- **兜底高亮。** 没有 tree-sitter 语法认领的文件改用 Sublime 语法:syntect 的默认语法集(覆盖 OCaml、LaTeX、D、Pascal、Tcl、Graphviz 等),加上从 bat 引入的宽松许可语法,例如 Julia、Crystal、nginx、Apache 配置、VHDL、SystemVerilog、Odin、WGSL、Org。各语法的许可见 `docs/third-party/SYNTAXES.md`。
- **重开后恢复终端内容。** mtty 退出时,保存每个终端最近 5000 行内容,颜色一并保留;如果当时开着 vim 或 less,保存的是它们底下的 shell 输出。重开后,先在新 shell 上方显示这些内容,随后删除保存的文件。文件只有你本人能读;设置项 `restore-scrollback = false` 或设置界面里的开关可以关闭此功能。
- **重新运行。** 退出时正在运行的程序(如 `vim notes.md`、`npm run dev`)会在恢复后提示"按回车重新运行";输入其他内容即放弃,绝不自动执行。(支持 macOS 与 Linux。)

## 修复

- **从 Dock、注销、关机或 AppleScript 退出时什么都不保存。** 这些操作走的是 AppKit 的退出流程,会直接结束进程;现在改走 mtty 自己的退出流程,会保存会话。
- **触控板滚动几乎不动。** 每个很小的像素增量都被舍成 0 行;现在会累加起来,终端和编辑器都已修复。
- **滚轮在 vim、less、man 里不起作用。** 现在在备用屏幕上,滚轮会发送方向键,与 iTerm2、Ghostty、Alacritty 的做法一致。

## 文档

- README、`docs/PRODUCT.md` 与 mtty.dev 中,mtty 的定位已改为 AI 原生的终端与编辑器。
- 编辑器 pane 的设计 ADR 0034 已接受,路线图新增 M5 到 M7 三个里程碑。
- 许可声明中的版权方改为 the mtty authors。

## 验证

- 发布提交在 macOS、Linux、Windows 上跑完整 CI,并完成四个 runner 的打包。
- **新增测试**:
  - 编辑器内核,外加 100 MB 文件的性能门:打开 36 ms,一次按键 0.0005 ms;
  - 每种内置语法的查询编译、文件类型识别和高亮;
  - 所有 Sublime 语法都能用纯 Rust 正则引擎解析;
  - 终端快照:颜色、折行内容的重新排版、宽字符、vim 底下的 shell 输出;
  - 保存内容的私有文件权限。
- **高亮性能门(Mac mini,release 构建)**:1 MB 文件首次解析 64 ms,按键后重新解析 3.5 ms,高亮一屏 0.09 ms。
- **用打好的 macOS 包实际截图验证**:一个高亮的 Julia 文件;以及用 AppleScript 退出后重新打开,恢复的 pane 正确显示了颜色、中文、重新排版的长行和 vim 的重新运行提示。

## 已知限制

- 应用变大了:因为内置语法,macOS 二进制约 88 MB(之前约 40 MB)。
- 重新解析移出 UI 线程之前,超过 1 MB 的文件不高亮。
- Markdown、超过 64 MB 的文件和远端文件仍用浮动编辑器打开。
- 编辑器 pane 的键盘输入、输入法和 ⌘S 还没有在每种桌面上手动检查过。
- 终端内容只在正常退出时保存,崩溃时会丢失;正在运行的程序不会在退出后继续存活,那需要一个独立的 PTY 守护进程。
- Windows 上没有"重新运行"提示。
- 构建尚未公证(macOS),也未签名(Windows)。
