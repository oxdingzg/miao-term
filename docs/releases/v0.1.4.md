# mtty v0.1.4

[简体中文](v0.1.4.zh-CN.md)

## Fixes and improvements

- **Responsive terminal shutdown.** Child termination and reaping run off the UI
  thread. Unix shells that ignore SIGHUP are forcefully terminated; Windows
  process-tree termination also runs in the background.
- **Bounded resource diagnostics.** A background recorder samples process CPU,
  RSS and render activity every 30 seconds. Resource logs are capped at 64 MiB;
  panic logs are capped at 2 MiB, including backups. Disable sampling with
  `MTTY_MONITOR=0`. See [Troubleshooting](../TROUBLESHOOTING.md).
- **Transactional Windows updates.** ZIP updates validate and stage all three
  executables before replacement, retain backups, and roll back failed updates.
  MSI exit codes are checked. See [ADR 0043](../decisions/0043-windows-update-transaction.md).
- **Agent editing and ACP.** Deleted proposal rows remain visible for review
  without entering copied or saved text. Whole-file proposals preserve unchanged
  context. ACP adds authentication, session loading and terminal callbacks;
  client file writes require review and saving, and commands require permission.
  Output and process counts are bounded.
- **Clipboard and transports.** Clipboard image forwarding supports Windows and
  X11 PNG encoding and text-paste cleanup; Wayland uses the existing data device.
  Serial reads retry idle timeouts and interruptions, and closing a pane stops
  its idle byte-pipe reader.
- Documentation and third-party licence notices refreshed.

## Verification

The source snapshot passed 531 macOS workspace tests, Clippy, formatting,
privacy checks and 14 release performance tests on a remote build host. Three
native Windows ConPTY tests passed. The release pipeline additionally checks
both macOS architectures, Linux AppImage/deb and Windows ZIP/MSI packaging,
installer contents and detached minisign signatures.

Further platform acceptance evidence and limits are recorded in
[ACCEPTANCE.md](../ACCEPTANCE.md). Apple Developer ID notarization and Windows
Authenticode signing remain dependent on owner credentials; detached minisign
signatures are provided separately. Claude ACP still needs provider authentication
for a real prompt.
