# v0.1.12

[简体中文](v0.1.12.zh-CN.md)

## Markdown writing in one pane

Markdown opens in a single writing pane. Click a rendered block to edit its
source in place, or switch to **Source** for the complete document. Undo, Redo,
and `⌘S`/`Ctrl+S` retain the existing document, history, and save path. Chinese
text, emoji, and external edits are covered by regressions. Read-only mode
disables live mutation.
An optional separate preview remains available.

This release completes the initial block-level editing phase of [#94](https://github.com/oxdingzg/mtty/issues/94).
Inline token-level source reveal, advanced tables, and the wider writing roadmap
remain tracked there.

## Terminal and input fixes

- Clear a pane's selection on main/alternate screen switches, preventing shell
  selection highlights from remaining over a full-screen TUI.
- Map Home/End and Ctrl+Home/Ctrl+End to the terminal sequences expected by
  line editors and TUIs.
- Publish shared shell-integration scripts atomically. Concurrent pane startup
  can no longer source a truncated script and lose command/output/cwd tracking.

## Verification and distribution

Remote workspace tests, Clippy, and release performance gates pass. An isolated
application capture verifies the new Markdown layout. Release packaging builds
both macOS architectures, Linux, and Windows; Linux packages and Windows MSI
installation/uninstallation are checked by the release workflow. Native desktop
IME automation was not exercised in this validation run.

Source checks are scoped to changed areas; a `ci-gate` still requires every
applicable check to succeed. Distribution contents continue to include the CLI,
PTY host, licences, and the updater manifest.
