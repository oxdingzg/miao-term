# mtty v0.1.7

[English](v0.1.7.md)

## 新功能

- **Pane 右键上下文菜单。** 终端 pane 现在右键弹出上下文菜单,取代原来的“有选区复制、否则粘贴”。
  菜单含 **复制**(有选区时)、**粘贴**、**复制 / 粘贴为**(复制为 ANSI 颜色、或粘贴为 Shell 转义)、
  **撰写**、**发送给 Agent…**、**全选**、**搜索…**、**关于本行**(指针下的行/列/字符与文本)、
  **分屏**、**清除回滚**。每一项都复用命令面板与快捷键所用的同一命令,行为与键盘路径完全一致。
- **向左 / 向上分屏。** 分屏菜单(以及命令面板)在向右/向下之外新增向左/向上;新 pane 落在近侧。
