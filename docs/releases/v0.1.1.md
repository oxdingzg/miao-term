# mtty v0.1.1

[简体中文](v0.1.1.zh-CN.md)

- **The Resume picker shows when a session was last seen.** Every reported
  session now carries a timestamp, and *Resume Agent Session…* shows a relative
  age (`5m ago`, `2h ago`, …) next to each one.
- **Adjustable quota warning.** `agent-quota-warn` in `config.toml` (default
  `80`, clamped to 0–100) sets the percentage at which the Agent tab marks an
  agent-reported quota.

Verification runs on GitHub Actions: full workspace CI and performance gates,
followed by four-runner packaging and installer checks.

[Full changes](https://github.com/oxdingzg/miao-term/compare/v0.1.0...v0.1.1)
