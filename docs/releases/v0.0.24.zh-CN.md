# mtty v0.0.24

- **标签状态遵循 `[badges]`。** `processing`、`idle`、`awaiting`、`error` 四个开关现在决定哪些 agent 状态显示在标签上。关闭某个状态后,处于该状态的标签显示为普通终端:没有状态圆圈,也没有完成或 `!` 标记。系统通知不受影响;四项默认全开。
- **Windows 上验证了 `keep-sessions-on-quit`。** 通过"退出"命令或关闭窗口退出时,运行中的程序都留在 PTY 宿主里,下次启动会重新接上。

验证在 GitHub Actions 上运行:完整的 workspace CI 与性能门禁,随后是四个 runner 的打包与安装器检查。
