# mtty v0.1.0

[简体中文](v0.1.0.zh-CN.md)

- **Resume an agent session.** *Resume Agent Session…* lists the sessions
  agents have reported (agent, session id, directory, most recent first) and
  relaunches the chosen one in the directory it ran in. `mtty-cli` and MTP
  gain `agent.sessions` and `agent.resume` (new `agent.resume` capability);
  the agent hook now reports its working directory.
- **Agent quota at a glance.** When an agent reports its usage, the Agent tab
  shows one compact line (`used/limit`, the window, and a ⚠ past 80%); mtty
  never calls a model or account API. `mtty-cli state --quota FILE|-` forwards
  a JSON quota with a state report.

Verification runs on GitHub Actions: full workspace CI and performance gates,
followed by four-runner packaging and installer checks.
