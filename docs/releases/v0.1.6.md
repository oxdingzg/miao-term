# mtty v0.1.6

[简体中文](v0.1.6.zh-CN.md)

## Features

- **Full kitty keyboard protocol.** The terminal now honours all five
  enhancement flags: disambiguate escape codes, event types (including
  release), **alternate keys** and **associated text**, plus all keys as
  escape codes. Shift+a is reported as `CSI 97:65;2u`, Shift+2 as
  `CSI 50:64;2u`, a Cyrillic ctrl+с still reaches the program as ctrl+c, and
  the bytes a key produced travel as the text sub-field. Read it in
  [PRODUCT.md](../PRODUCT.md).
- **Inline images keep their layer.** Kitty graphics placements now carry their
  z-index, so negative-z images draw behind the text grid while z≥0 images draw
  above it, still clipped to their pane.
- **Images come back with a session.** A restored pane brings its inline
  images back with the restored scrollback, anchored to the same text row, when
  the pane returns at the same width. Images larger than the store cap or
  older than the captured rows are dropped, and a Kitty animation returns as a
  still frame.
- **Search inside files and scrollback.** Open Quickly (`⌘⇧O`) now matches text
  inside files in the current directory and inside the active pane's
  scrollback, off the UI thread and bounded by file count, size and time; a
  file hit opens the editor at the line, a scrollback hit scrolls and
  highlights the match.
- **Remote editing follows the remote file.** An editor pane over ssh now polls
  the remote file's length and mtime in the background and reloads in place
  when it changes underneath the pane and there are no unsaved edits — the
  same behavior local files already had.
- **Whole folders over FTP.** The FTP/FTPS browser uploads and downloads whole
  directories recursively, creating local folders before fetching and remote
  folders before sending.
- **Opt-in SSH reconnect.** `ssh-auto-reconnect = true` connects restored SSH
  tabs on startup instead of waiting for Enter (default off, host-key
  verification unchanged).

## Fixes

- **Wide-character copy.** Copying a selection that began on the trailing half
  of a CJK character dropped it while the mirror-image drag kept it; both
  directions now keep the character whole, and a wrapped character's leading
  spacer can no longer leak in.
- **PowerShell 5.1 history.** Windows PowerShell 5.1 now records command
  history through the same `PSConsoleHostReadLine` hook as 7.x.
- **Render pacing and glyph atlas.** Hidden, minimized and occluded surfaces no
  longer submit GPU work; redraws are coalesced and timer wakes are compacted;
  the previous frame's glyph atlas pins are released every frame so the LRU can
  evict; renderers for closed panes are dropped.

## Chores and documentation

- The repository, its engine crates and the crate directories are now `mtty-*`.
- Release notes are English with a Simplified Chinese link; third-party
  terminal references are removed; the roadmap records the real mosh
  verification.

## Verification

The source snapshot passes the workspace test suite, Clippy, formatting, and
privacy checks on CI, followed by the four-runner packaging and installer
checks (macOS both architectures, Linux AppImage/deb, Windows ZIP/MSI) with
detached minisign signatures. Apple Developer ID notarization and Windows
Authenticode signing remain dependent on owner credentials.
