# mtty v0.0.25

[简体中文](v0.0.25.zh-CN.md)

- **Windows text is no longer garbled.** Each pane's console now runs on a
  UTF-8 code page (cmd, PowerShell and Git Bash), so a program that writes
  UTF-8 bytes instead of going through `WriteConsoleW` — Bun and the native
  TUI renderers, such as the one behind miao — no longer shows CJK as mojibake.
- **Open Externally.** A new command (and View-menu item) hands the active
  editor's file to the system's default application; a terminal pane falls back
  to its own directory.
- **Jump-to-line highlight.** Go to Line, Go to Symbol, Jump to Selection and
  MTP `app.edit`/`app.view` flash the line they land on.
- **More of the kitty keyboard protocol.** Event types (including release) and
  "report all keys as escape codes" are honoured on top of disambiguation.

Verification runs on GitHub Actions: full workspace CI and performance gates,
followed by four-runner packaging and installer checks.
