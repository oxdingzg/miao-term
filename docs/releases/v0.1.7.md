# mtty v0.1.7

[简体中文](v0.1.7.zh-CN.md)

## Features

- **Right-click pane context menu.** Terminal panes now open a context menu on
  right-click, replacing the old copy-or-paste behavior. It offers **Copy**
  (when there is a selection), **Paste**, **Copy / Paste as** (as ANSI
  colours, or paste shell-escaped), **Composer**, **Send to Agent…**,
  **Select All**, **Search…**, **About This Line** (the row, column, character
  and text under the pointer), **Split Pane** and **Clear Scrollback**. Every
  item reuses the same command as the palette and shortcuts, so nothing behaves
  differently from the keyboard path.
- **Split Left and Split Up.** The split menu (and the command palette) adds
  Left and Up to Right and Down; the new pane lands on the near side.

## Fixes and integration

- The Windows PowerShell 5.1 command-history fix is now verified end to end on
  a logged-on Windows desktop (a scripted acceptance that types marked commands
  into a 5.1 pane and reads them back over MTP). See
  [WINDOWS-PS51-HISTORY.md](../WINDOWS-PS51-HISTORY.md).
- Desktop-only acceptance notes for the IME candidate anchor and inline-image
  session restore are recorded in [ACCEPTANCE.md](../ACCEPTANCE.md).

## Verification

The source snapshot passes the workspace test suite, Clippy, formatting, and
privacy checks on CI, followed by the four-runner packaging and installer
checks (macOS both architectures, Linux AppImage/deb, Windows ZIP/MSI) with
detached minisign signatures. The pane context menu was checked in a real macOS
window. Apple Developer ID notarization and Windows Authenticode signing remain
dependent on owner credentials.
