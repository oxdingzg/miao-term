# mtty v0.0.18

本次补丁保留 TUI 绘图颜色，并修正侧栏按钮。

- **TUI 边框保留原色。** 制表与块状绘图字符不再应用文字对比度增强。
  miao 输入框底部的深色半格边缘会融入面板，不再显示为灰条；普通文字继续保持可读性增强。
- **侧栏按钮对应面板位置。** 左右侧栏切换按钮使用对应图标，并修正排列顺序。
- **ACP 测试支持所有平台。** 假代理传输改用回环 TCP，替代仅 Unix 可用的 socket，
  Windows 也能运行相同的协议往返测试。

验证在 GitHub Actions 上执行：完整 workspace CI 与性能门禁，以及四 runner 打包和
安装包检查。本机无需编译。

[完整变更](https://github.com/oxdingzg/miao-term/compare/v0.0.17...v0.0.18)
