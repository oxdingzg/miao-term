# mtty v0.1.2

- **Chinese IME punctuation on macOS.** Typing `.` with the built-in Pinyin
  input method inserted the full-width `。` (and a visual gap) instead of `.`:
  winit dropped the IME's direct commit and sent the keyboard layout's own
  character, and mtty's IME reply path never saw the real one. mtty now carries
  a patched winit that keeps the IME's committed string, so `1.0.0` types as
  `1.0.0`. Regular (non-IME) input is unchanged. Upstream: winit #3925.

Verification runs on GitHub Actions: full workspace CI and performance gates,
followed by four-runner packaging and installer checks.
