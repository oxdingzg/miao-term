# mtty v0.1.8

[English](v0.1.8.md)

## 修复

- **tab 标题跨重启保持一致。** 未重命名过的 tab 显示的是自动标题——窗格程序的 OSC 名称、其次是当前
  目录、最后是 `shell N`。这个标题此前未存入会话,重启后新 shell 的标题会将其覆盖,于是 tab 回来时变成
  运行程序的名字,而不是重启前的标题。现在会保存并恢复**显示中的标题**,重启后显示同一标题;你重命名过的
  tab 仍保留你选定的名字。

## 验证

源码快照通过工作区测试、Clippy、格式化与隐私检查的 CI 验证,随后是四平台打包与安装器检查
(macOS 双架构、Linux AppImage/deb、Windows ZIP/MSI)及分离的 minisign 签名。标题优先级由单元测试覆盖。
Apple Developer ID 公证与 Windows Authenticode 签名仍依赖所有者凭据。
