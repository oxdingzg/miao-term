# mtty v0.1.6

[English](v0.1.6.md)

## 新功能

- **完整的 kitty 键盘协议。** 终端现在支持全部五个增强 flag:消歧义转义、按键事件类型(含释放)、
  **替代键**与**关联文本**,以及全键转义。Shift+a 上报为 `CSI 97:65;2u`,Shift+2 为
  `CSI 50:64;2u`,西里尔布局下的 ctrl+с 仍以 ctrl+c 送达程序,按键产生的文本进入文本子字段。
  详见 [PRODUCT.zh-CN.md](../PRODUCT.zh-CN.md)。
- **内联图片按层绘制。** Kitty 图形放置现在携带 z-index:负 z 的图片绘制在文本网格之下,z≥0 的
  绘制在其上,仍裁剪在各自窗格内。
- **会话恢复带回图片。** 恢复的窗格会随回滚缓冲一并带回内联图片,锚定到同一文本行(要求窗格以
  相同宽度返回)。超出存储上限或早于所捕获行的图片会被丢弃,Kitty 动画以静帧返回。
- **在文件内容与回滚中搜索。** 快速打开(`⌘⇧O`)现在还会在后台、按文件数/大小/时间受限地匹配当前目录
  文件内容与活动窗格的回滚文本;文件命中在编辑器中打开并定位到行,回滚命中滚动并高亮。
- **远程编辑跟随远端文件。** ssh 上的编辑窗格现在会在后台轮询远端文件的长度与 mtime,在无未保存修改
  时原地重载——与本地文件一致。
- **FTP 整目录传输。** FTP/FTPS 浏览器可递归上传/下载整个目录,下载先建本地目录、上传先建远端目录。
- **可选的 SSH 自动重连。** `ssh-auto-reconnect = true` 时,恢复的 SSH 标签在启动时自动重连,无需按
  Enter(默认关闭,主机密钥校验不变)。

## 修复

- **宽字符复制。** 从 CJK 汉字右半边开始的选择会漏掉该字符,而反向拖拽会保留;现在两个方向都保留完整
  字符,换行汉字的 leading spacer 也不会再混入。
- **PowerShell 5.1 历史。** Windows PowerShell 5.1 现在与 7.x 一样经 `PSConsoleHostReadLine` 钩子
  记录命令历史。
- **重绘节流与字形图集。** 隐藏/最小化/被遮挡的表面不再提交 GPU 工作;重绘被合并、定时唤醒被压缩;
  每帧释放上一帧的字形图集占用,使 LRU 能回收;关闭窗格的渲染器被释放。

## 杂项与文档

- 仓库、引擎 crate 与 crate 目录均改名为 `mtty-*`。
- 发布说明统一为英文并附简体中文链接;移除第三方终端引用;路线图记录真实的 mosh 验收。
