# mtty v0.1.13

[English](v0.1.13.md)

## 修复

- **实时程序标题优先于项目别名。** 当 `views.json` 配置了 `projects` 时,项目下的
  每个 tab 都只显示裸的项目别名,导致同一仓库里运行不同 agent 的两个 tab 看起来
  完全一样,即使各 pane 上报了不同的实时 OSC 标题。现在,只要没有规则模板或规则
  别名固定标题,非空的实时标题就优先于项目别名。显式规则标题与规则别名仍然优先于
  一切,pane 未上报标题时仍回退到项目别名与目录名,`{alias}` 模板继续渲染项目名。
  (#106)

## 验证

源码快照在 CI 上通过工作区测试、Clippy、格式与隐私检查,随后通过四平台打包与
安装器检查(macOS 双架构、Linux AppImage/deb、Windows ZIP/MSI),产物带 minisign
分离签名。Apple Developer ID 公证与 Windows Authenticode 签名仍依赖所有者凭据。
