# mtty v0.2.0

[English](v0.2.0.md)

## 全新的应用图标

应用图标改为透明背景、纯黑线稿的戴礼帽猫,取代原先的终端箭头图案。macOS 应用
包图标(由共享 PNG 生成)与 Windows 的窗口、任务栏和 MSI 图标(共享 ICO)都使用
它。ICO 含 16×16 到 256×256 共九个尺寸,全部 32 位带 alpha——包括 20 px 与
40 px 任务栏尺寸——因此四角保持透明、小尺寸依旧清晰。位图之外还提交了可编辑的
SVG 源文件。(#109、#110)

## 修复

- CI:`ci-gate` 聚合门禁改为按实际运行这些 job 的同一个标志来决定必需项,assets
  或 scripts 单类改动不再因被有意跳过的 job 而失败。(#111、#112)
- Windows 图标资源检查允许图稿包含额外尺寸,共享图标可以携带更多任务栏尺寸而
  不影响打包。(#113、#114)

## 验证

源码快照在 CI 上通过工作区测试、Clippy、格式与隐私检查,随后通过四平台打包与
安装器检查(macOS 双架构、Linux AppImage/deb、Windows ZIP/MSI),产物带 minisign
分离签名。Apple Developer ID 公证与 Windows Authenticode 签名仍依赖所有者凭据。
