# mtty v0.1.11

[English](v0.1.11.md)

## 修复

- **重启后 tab 标题不再冻结。** 会话保存的标题会永远占住恢复的 tab:它优先于
  一切自动标题且从不清除,每次保存还把它原样写回,于是 tab 一直停在重启前的
  名字上,`cd`、agent 与程序标题都不生效,视图规则引擎(ADR 0007)也从未作用于
  它 (#88)。现在保存的标题只在 pane 尚未上报实时上下文时占位——拿到工作目录
  或程序标题后,视图规则、程序标题与目录名重新生效 (#89)。重启后、pane 上报
  之前,tab 仍先显示上次退出时的标题。

## 验证

源码快照在 CI 上通过工作区测试、Clippy、格式与隐私检查,随后通过四平台打包与
安装器检查(macOS 双架构、Linux AppImage/deb、Windows ZIP/MSI),产物带 minisign
分离签名。Apple Developer ID 公证与 Windows Authenticode 签名仍依赖所有者凭据。
