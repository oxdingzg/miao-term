# mtty v0.0.7

[简体中文](v0.0.7.zh-CN.md)

A Windows release. v0.0.6 started on Windows for the first time; testing it on
a real Windows 11 desktop found these problems, all fixed and checked on that
machine. macOS and Linux behave as in v0.0.6.

## Fixes (Windows)

- **Switching the input language hung mtty.** The window stopped responding
  for good after switching to (or from) a Chinese input method. wgpu probed
  its OpenGL backend, which leaves a thread owning a hidden window that never
  processes messages; Windows tells every thread's windows about a language
  change and waits for them. mtty now uses DX12 and Vulkan only on Windows
  (`WGPU_BACKEND` still overrides). Found with a symbolized minidump.
- **SSH sessions did not start.** Every ssh command mtty typed into cmd.exe
  failed: POSIX quoting, `clear;` and ControlMaster options. Commands are now
  written for the pane's shell (cmd or PowerShell), without ControlMaster,
  which Windows' OpenSSH lacks. This covers New SSH Session, saved hosts,
  reconnects and snippets on hosts. Hosts set to *Connect with mosh* use ssh
  on Windows, which has no native mosh client.
- **Settings were ignored.** Windows has no `HOME`, so mtty had no config
  directory: `config.toml`, hosts, snippets, sync and sessions did nothing.
  They now live in `%APPDATA%\mtty` (state in `%LOCALAPPDATA%\mtty`); an
  existing `~/.config/mtty` under a Git Bash `HOME` keeps being used.
- **A console window opened** next to mtty, and closing it closed mtty.
- **The Quick Terminal hotkey typed its key** (the Y of Ctrl+Alt+Y) into the
  new pane: keys still held when the window gains focus are no longer typed.
- **Dropped paths** used single quotes, so a path with a space was split in
  cmd; they now use double quotes.
- `mtty --version` prints when redirected or run from a console.

## Verification

- Full CI on macOS, Linux and Windows, and the four-runner packaging
  rehearsal, on the release commit.
- On a real Windows 11 desktop: typing, Tab completion, menus, Microsoft
  Pinyin (preedit, candidate placement, commit), repeated input-language
  switches, file drops, clipboard (Ctrl+Shift+C/V), the Quick Terminal
  hotkey, config read from `%APPDATA%\mtty`, and New SSH Session reaching
  ssh's host-key prompt.

## Known limits

- Builds are not notarized (macOS) or code-signed (Windows) yet.
- mosh support is tested only as command construction; the AppImage and
  Windows install-and-relaunch helpers are unit-tested but have not run on
  those desktops.
