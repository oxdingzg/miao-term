# ADR 0043 — Windows 更新辅助程序的事务替换

[English](0043-windows-update-transaction.md)

状态：已接受。替代 ADR 0025 中的 Windows 辅助程序选择。

## 背景

旧批处理在解包或复制失败后仍会继续，可能留下不同构建混合的可执行文件；也没有检查 MSI 的失败返回码。
Windows 真机验收还暴露了独立辅助进程的引号与中文路径要求。

## 决定

使用带 UTF-8 BOM 的 PowerShell 脚本，以 `CREATE_NO_WINDOW` 直接启动。
脚本等待应用退出后才开始替换。

ZIP 在安装目录内使用唯一暂存目录，解包并验证 `mtty.exe`、`mtty-cli.exe` 和 `mtty-ptyhost.exe`，
然后把旧程序移动到备份并替换三个文件。失败时恢复所有已移动文件；回滚成功后重新启动旧应用，
回滚本身失败则保留备份。

MSI 等待 `msiexec` 完成，检查成功/需重启的返回码，只重新启动存在的安装。
失败不能报告为升级成功。

## 影响

下载包仍须先通过签名校验。辅助程序处理替换失败，不新增启动后的应用健康握手。
测试在 Windows 实际执行生成的 PowerShell 脚本，覆盖坏压缩包、文件占用及含空格、中文和引号的路径。
